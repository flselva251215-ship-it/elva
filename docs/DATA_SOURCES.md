## 时间、延迟与财务口径

- 选择免费日线工作流，不宣称逐笔实时。Twelve Data/AKShare通常只返回交易日期，API明确 `timestamp_precision=date`。界面显示报价日期、抓取时间、延迟说明，不把程序抓取时刻冒充报价时刻。内部午夜锚点只用于日期索引，不是实际午夜成交。
- 当日返回的日线可能尚未收盘，延迟分钟数没有供应商证据时显示未知，不编造“延迟15分钟”。盘中收益不根据无时刻数据猜测，今日盈亏可为空；最近参考交易日另列。
- 行情采用未复权价格，支持参考市值与移动平均成本盈亏；股息、拆股、资金流尚未处理，不能把回溯曲线称为精确总回报。
- 股票/汇率缓存独立于演示 `PriceBar`/`FXRate` 表。真实模式不读取演示报价；报价缺失时对应市值/盈亏为空，汇率缺失时不合并异币种。单账户原币可独立计算仓位。
- 资产曲线按单账户原币、交易账本和共同的已结束交易日收盘数据回溯，不用今天汇率伪造历史汇兑收益。初始账户含演示持仓，真实行情不使演示持仓变成用户真实资产。
- 模拟交易保留独立虚拟账本与明确标注的虚构成交样例，与真实行情估值隔离；没有任何券商下单代码。

## 缓存、刷新与安全

- `FeedCache` 持久保存实际成功响应及原始抓取时间。上游失败保留旧缓存和时间、附带错误；缺缓存则缺失，不补随机数或样例价格。
- 页面普通GET只读取缓存；页面首次联网加载及显式“更新真实行情”才发刷新请求。成功缓存6小时，失败退避5分钟；请求预占冷却15分钟，避免多个标签/进程同时请求同一标的。
- SQLite先预占再发网络请求，不在网络等待期间长期锁住整个账本。Twelve Data本机保守预算为4次/分钟、500次/UTC日，计数跨重启保留。**这不是对供应商免费配额的承诺**，账户控制台才是当前权益依据。收到429后不循环重试。
- 只有只读行情GET，没有付费订阅、账单、券商连接或交易接口。API密钥只从服务器 `TWELVE_DATA_API_KEY` 获取，通过认证头发送；不放在URL、API响应、前端包、localStorage或日志。外部错误被替换为脱敏说明。
- 当前后端仅监听本机，并检查Host/跨站请求。若今后需要公开部署，必须先独立核实公开展示授权及增加鉴权/TLS，不能直接放开Host。
