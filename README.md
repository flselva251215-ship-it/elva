# AI StockPilot

可本地启动的中文股票投资管理 MVP：美股 / A 股持仓、解释性股票分析、亏损诊断、风险预警和独立虚拟账户模拟交易。

**第一阶段只有分析与模拟，没有券商连接、真实账户授权或实盘下单代码。** 全部行情、历史价格、初始持仓及汇率均为明确标注的虚构样例；首次启动不需要任何密钥。默认 AI 是可复核的规则引擎，尚未调用大语言模型，不保证收益或回本。

## 本地运行完整代码

首次只体验虚构数据时，在安装后运行 `bash scripts/start-demo-preview.sh`。它会创建独立临时演示数据库，不修改 `data/stockpilot.db`，不需要密钥。默认端口8030，仅本机访问。

### 完整前后端版本

依赖：Linux/macOS、Python 3.12+、Node.js 22+、npm。Windows 推荐 WSL2。无需 Docker、Redis 或外部数据库。

```bash
cd /workspace/elva           # 本地克隆时进入实际项目目录
```

## 已实现的使用闭环

1. **资产总览**：单账户 / 合并视图、现金、市值、今日数据状态、最近样例交易日盈亏、累计盈亏、已实现与未实现收益、累计收益率、按实际数据绘制的资产配置图、可交互演示价格图、风险摘要与观察池/模拟/报告入口。
2. **我的持仓**：按名称 / 代码检索，按市场筛选及仓位 / 收益率排序，录入历史成交，点击持仓进入诊断。
3. **持仓诊断**：平均成本、持仓收益、仓位和人民币折算贡献、波动、回撤、透明风险评分；亏损时列出继续持有 / 逐步减仓 / 退出三种情景及费用、滑点、假设与触发条件。显示来源、时间和公式。
4. **股票研究**：6 个演示标的搜索、筛选、排序和收藏；历史价格图、MA20、RSI14、年化波动、最大回撤及透明研究评分。估值、财报、复权等不可用数据明确标注。
5. **模拟交易**：独立虚拟资金、待成交 → 已成交 / 已拒绝 / 已撤销、手动执行、费用和滑点、交易计划备注、持仓与盈亏、复盘快照和审计。
6. **风控中心**：单股 / 行业比例、亏损阈值、现金底线、单笔模拟金额上限；集中度、波动、回撤、样本相关性、过期行情 / 汇率与收盘大幅变化预警；股票下跌 5% / 10% 和美元贬值 5% 假设压力测试。
7. **导入与设置**：CSV 模板、文件 / 文本上传、原子预检、重复行提示、行级错误、导入确认、成交编辑、删除确认、可校验的模拟规则 JSON 编辑、持仓 CSV 导出、报告 JSON 下载及本地操作审计。

### 体验一笔模拟买入与卖出

进入“模拟交易”，保留美元虚拟账户 / AAPL / 10 股，点击“创建模拟订单”。勾选 **“我确认使用历史演示时钟成交”** 后，点击待成交订单的“模拟成交”。把方向切为模拟卖出，再创建 10 股订单并模拟成交。

在默认规则下，买入价 USD 224.61、卖出价 USD 224.39、两笔手续费各 USD 1.00；平仓已实现盈亏为 **USD -4.20**，虚拟现金 **USD 99,995.80**。这是模拟滑点和费用损耗，不是实际市场成交。

不勾选演示时钟时使用系统真实时间；行情超过 24 小时或不在规则时段内会拒绝成交。历史演示时钟使用对应标的最新样例 bar 的时间，不等于当前时间；A 股同一历史演示日买入不能当天卖出，仍受 T+1 规则限制。本版不提供推进演示日期的功能，跨日卖出场景由自动化规则测试覆盖。

待成交订单不冻结现金或股票；每次执行取得 SQLite `BEGIN IMMEDIATE` 写锁，再读取账本和校验，可避免并发超卖 / 双重成交；拒绝会保存状态和原因。订单不可再次成交，模拟成交不可从交易编辑页修改或删除。

### CSV 格式

```csv
account_id,symbol,side,quantity,price,fee,traded_at
1,AAPL,buy,10,220,1,2026-10-15T10:00:00-04:00
2,600036,buy,100,38,5,2026-10-15T10:00:00+08:00
```

支持 UTF-8/BOM，单批不超过 1 MB / 1,000 行。字段与模板完全一致；side 只能是 buy/sell，数量与价格必须正数，费用非负，时间必须包含时区且不能在未来，股票币种须与账户匹配。按 UTC 成交时间排序重放账本。相同账户 / 标的 / 方向 / 数量 / 价格 / 费用 / UTC 时间计算去重指纹；重复项跳过，任一错误整批不写入。可先预检再确认提交。请勿在同一时点导入两笔字段完全相同但实际不同的成交，本版没有券商成交 ID 区分它们。

## 财务与风险计算口径

- 所有资金、价格、数量、持仓成本用 Python `Decimal` 计算，SQLite 以文本存储避免 NUMERIC 经过 float；API 以字符串返回。浮点只用于非资金统计指标及前端格式化 / 图表。
- 采用**移动加权平均成本**。买入成本增加 `股数×成交价+手续费`。卖出移除 `卖出股数×此前平均成本`，已实现盈亏为 `卖出金额−卖出手续费−移除成本`。未实现盈亏为 `当前样例市值−剩余成本`。全仓卖出后成本为零。不允许做空或历史现金为负。
- 权益 = 现金 + 持仓市值；累计收益率 = `(已实现+未实现盈亏)/初始投入`，不是年化、TWR 或 IRR。初始投入固定，不支持入出金、股息、拆股、公司行为或外汇买卖；不会将它们冒充成交。
- 最近样例交易日盈亏 = 当日末权益 − 上一交易日末权益，按截止时间重放成交并计入手续费。行情日期不是市场本地今日时，“今日盈亏”为空，最近样例交易日另行展示；如果已有成交晚于最新样例行情，单日盈亏也为空，避免混合不同时点。
- 1 USD = 7.10 CNY 是固定虚构汇率，注明日期与来源。多币种先分别核算再演示折算；汇率缺失时合并字段为 null，不直接相加。汇率过期明确预警，不计算真实汇兑收益。不同市场估值时点不完全一致。
- 仓位 = 折人民币股票市值 / 含现金总资产；行业敞口是对应仓位之和。组合贡献显示未实现盈亏折人民币金额。资产配置环图按实际样例占比计算。
- MA20：20 个收盘均值；RSI14：14 期简单平均涨跌比（非 Wilder 平滑）；波动率：日对数收益样本标准差 × √252；历史最大回撤：价格 / 迄今最高价 − 1。相关性：日期对齐的简单日收益 Pearson 相关系数，至少 20 个样本，>0.8 提示。合成序列相关性没有真实投资意义。
- 风险分（0–100）：单股超限 +35，持仓亏损超限 +35，波动 >35% +15，历史回撤超承受阈值 +20，行情缺失或过期 +20，收盘变化 >5% +15。分数≥50 为风险偏高，0<分数<50 需要复核；0 分仍不代表安全。
- 研究分：价格≥MA20 得40分否则10分；RSI14在30–70得30分否则10分；波动<35%得30分否则10分。支持评分 / 波动排序，暂不支持自定义权重。
- 风控单股/行业/亏损设置生成预警，不阻止历史记录；模拟成交强制检查单笔原币金额上限、买入现金底线、可用资金、可卖股数、交易单位、交易时段、成交量参与上限及配置涨跌幅。
- 亏损情景相对**当前市值**计算余仓±10%的假设变化，扣除卖出部分的费用与滑点，不代表已实现总收益。半仓减持向下取整到板块交易单位；全仓退出允许一次卖出剩余零股。退出仍有费用损失。补仓不会保证回本。

## 模拟规则范围与来源

`backend/app/market.py` 定义默认规则，首次启动写入 `ExecutionRule` 表，之后可通过设置页 / API 校验修改并留审计。

| 规则映射 | 示例标的 | 买入单位 | 可卖限制 | 日涨跌幅 | 时区与常规时段 |
|---|---|---|---|---|---|
| CN_MAIN | 600519 / 600036 | 100 股 | T+1 | 10% | Asia/Shanghai 09:30–11:30 / 13:00–15:00 |
| CN_GEM | 300750 | 100 股 | T+1 | 20% | Asia/Shanghai 同上 |
| US_REGULAR | AAPL / NVDA / MSFT | 1 股 | 允许同日卖出，仅模拟 | 无固定日幅度 | America/New_York 09:30–16:00，自动夏令时 |

仅模拟工作日普通时段，不含交易所节假日 / 半日市 / 集合竞价 / 临停 / ST / 新股 / 全部板块规则。A 股买入费率 0.03%、最低 CNY 5，卖出额另计 0.05% 假设税；美股 0.01%、最低 USD 1；双向滑点 0.05%、单笔日样例成交量参与上限 1%。费率是教学参数，不等同任何券商实际收费。未模拟真实订单簿、排队、流动性冲击、融券或美股 T+1 现金结算 / 券商约束。涨跌幅只检查参考昨收后的模拟成交价，不保证涨停时能真实买入。

参考入口：[上交所交易规则](https://www.sse.com.cn/lawandrules/)、[深交所规则](https://www.szse.cn/lawrules/)、[NYSE 交易时段](https://www.nyse.com/markets/hours-calendars)。本版未认证完整法规覆盖，禁止据此接入真实交易。

## 限制与后续阶段

这是可运行 MVP，非完整生产投资平台。尚未实现实时授权行情、LLM 中文解释服务、全市场标的录入、公司行为/股息/出入金、真实收益曲线与基准超额收益、TWR/IRR、完整交易日历、可推进模拟时钟、真实结算、账户自定义、PostgreSQL/Alembic 迁移、Docker Compose、多用户权限与生产运维。首页曲线明确是样例价格图，日报/周报是生成时点快照，不能当作实际期间绩效。

后续先接入获授权的数据供应商并验证时效/复权，完善账户现金流与公司行为及交易日历，再加入结构化 LLM 解释和身份验证。真实资金交易始终不属于本阶段；未来任何扩展都需要独立开发与授权、逐单确认、限额、审计、停止开关及券商和司法辖区规则验证。
